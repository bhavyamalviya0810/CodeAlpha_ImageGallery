# CodeAlpha Image Gallery

A modern and responsive Image Gallery built using HTML, CSS, and JavaScript as part of the CodeAlpha Frontend Development Internship.

## 📌 Project Overview

This project showcases a visually appealing image gallery with category-based filtering, interactive lightbox viewing, keyboard navigation, smooth animations, and responsive design. Users can browse images by category and view them in an immersive fullscreen mode.

## ✨ Features

- Responsive image gallery layout
- Category-based image filtering
- Interactive lightbox/modal view
- Previous and Next image navigation
- Keyboard controls:
  - Left Arrow → Previous Image
  - Right Arrow → Next Image
  - Escape → Close Lightbox
- Smooth hover effects and transitions
- Modern dark-themed user interface
- Mobile-friendly responsive design
- Organized image categories:
  - Nature
  - Technology
  - Animals
  - Travel

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Run index.html in your browser.

Or start a local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
